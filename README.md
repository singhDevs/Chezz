# Chezz
A real-time Chess game android app built using web-sockets.

## Features
- Real-time multiplayer chess with timed matches. Game ends on checkmate, draw or timer expiry.
- Secure Google sign-in and PostgreSQL storage. Supports cross-device game data access
- In-game options to resign, offer draw, and play Rated or Casual (unrated) matches.
- Implemented Glicko-2 rating system for dynamic skill tracking in rated games.
- PGN export feature for game sharing and analysis.
